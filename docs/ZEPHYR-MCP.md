# Optional live Zephyr access
First release uses exports. No credentials or live case changes are needed. The actual SmartBear client inspected at commit `27ce458080579b7e2cb60d0e81995ab0f0c85c5f` calls `https://api.zephyrscale.smartbear.com/v2`, describes a Zephyr Scale API token, and registers test-case/step/project tools. This establishes compatibility with **Zephyr Scale Cloud v2**, subject to account permissions and region. It does not establish support for Server/Data Center, Essential/Squad, or every product called Zephyr. Keep those editions unverified until their official endpoint/auth compatibility is checked.

Only after confirming Scale Cloud v2 and your region, configure your MCP client's stdio server with command `npx`, args `-y`, `@smartbear/mcp@latest`, and local environment `MCP_CLIENTS=Zephyr`, `ZEPHYR_API_TOKEN` from your secret store and `ZEPHYR_BASE_URL` set to your verified regional v2 endpoint. The default inspected endpoint is the one above. Use your host's MCP configuration UI; this repo does not write it. Pin the resolved package version for your work environment after review.

The upstream README also advertises hosted `https://zephyr.mcp.smartbear.com/mcp` with OAuth; that is an alternative requiring account eligibility and company approval, not evidence of broader edition compatibility. Live setup was not tested. The developer integration documentation returned a login screen during this build.

Begin with read-only project/case/step retrieval and compare returned fields with a known exported case before any automation. Do not expose tokens in prompts/reports or commit config secrets. Case creation/update and execution uploads are separate actions requiring an explicit user request; installing these skills does not enable them.

Sources: [SmartBear README](https://github.com/SmartBear/smartbear-mcp/tree/27ce458080579b7e2cb60d0e81995ab0f0c85c5f), [client implementation](https://github.com/SmartBear/smartbear-mcp/blob/27ce458080579b7e2cb60d0e81995ab0f0c85c5f/src/zephyr/client.ts), [integration documentation](https://developer.smartbear.com/smartbear-mcp/docs/zephyr-integration).
